# 真机与 TestFlight 验收

以下为待执行清单。每行起始状态为 **NOT_VERIFIED**。以同一个正式候选运行，记录 commit、版本/构建号、Archive 与二进制哈希、设备/iOS、地区、网络、时间、操作、结果和证据路径。写入类检查使用隔离 Supabase、API、OSS 与测试作品。避免在现有手机上清除真实用户资料。

## 设备矩阵

| 设备或环境 | 必跑范围 |
|---|---|
| iOS 17 的紧凑屏 iPhone，真机或可用模拟器 | 首次启动、滤镜/动画回退、Safe Area、横竖屏、键盘、相册权限；模拟器结果单独记录。 |
| 当前稳定 iOS 27.2 的普通 iPhone 与 ProMotion iPhone | 全旅程、120Hz 设备策略、空间 Metal/Core Motion、前后台、相册分享、性能。 |
| iPad（产品目前声明支持） | 横竖屏、大小尺寸、安全区、点按与键盘、地图、分享 popover、全屏行为；核对支持设备与 Connect 截图。 |
| 可连的 Windows/WSL iPhone | 确认解锁与信任，核对 BUSID。按开发说明从管理员 PowerShell 配置仅限 WSL 的苹果驱动转接，再运行 xtool devices --no-wait、idevicepair validate、idevicedevmodectl list。记录系统版本，优先跑设备冒烟。 |

## 性能与稳定性

在两类 iPhone 上用 Instruments 或等价真机采集。分别在冷缓存与热缓存运行至少 5 次，记录 App 启动到可交互、首屏图片到齐、Frame Pacing/hitch、主线程时间、峰值和恢复内存、CPU、缓存磁盘 I/O 与空间模式前后台 GPU/耗电。持续滚动、反复开关查看器及地图、并发大图、低存储与热状态要分开记录。保留 Instruments 或 MetricKit 产物；先建立基线并由团队确认门槛。

## 补齐的自动化用例设计

- 本地测试 API 用可控响应替换网络层，覆盖读目录错误、图片重试、地图 401/403/429/500、点赞超时和幂等性、景深 URL 过期重签及取消并发。准备 1001 条、重复 ID、坏坐标、非公开作品和大图夹具。
- 用 XCUITest 测首装、导航和刷新、三类胶卷卡与详情、上下/横向手势、相册拒绝、定位恢复、收藏持久化、RTL 和最大字级。Metal/姿态、系统提示和帧时另保留人工/性能仪器证据。
- 用 App Store 导出配置的同一 Archive 核验版本、签名、隐私清单、可执行 SDK 及 dSYM，上传/测试安排由有权限的发布负责人执行。
