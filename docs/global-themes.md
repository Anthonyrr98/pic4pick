# 全局主题

前台右上角与后台的「外观」按钮提供两个主题：

| 主题 | 氛围 | 卡片 | GSAP 切换节奏 |
| --- | --- | --- | --- |
| 纸白 `paper` | 纸白、深绿、通透留白 | 20px 圆角 | 340ms，power2.out |
| 暖调 `film` | 奶油纸、陶土、细纸纹 | 6px 圆角，纸色边框 | 560ms，power2.inOut |

主题覆盖图库、发现面板、地点弹窗、照片详情、管理后台和加载页。摄影图像不添加主题色滤镜；地图底图仍由后台的「地图样式」配置控制。

图库进入「胶片」分类时临时启用 `darkroom` 暗房相册：暖炭黑背景、冲印橙选中态、相纸留白、真实胶卷型号与顺序编号。照片保留原有色彩，不添加滤镜。详情弹窗与外观菜单一起切换；离开胶片分类、进入发现或卸载图库时恢复用户所选的外观。临时主题不写入 `pic4pick_theme`，其他标签页不受影响。在胶片分区选择外观会更新离开该分区后的偏好。

胶片卡片使用用户提供的横/竖 135 胶片边框，根据已加载图片的宽高选择方向，并以原比例显示照片。缩略图只保留边框和照片，不显示外层相纸、标题、地点、收藏或胶卷尾注；作品名称仍用于图片替代文字和打开按钮的无障碍名称。`public/film-frames/` 保存未经修改的源 PNG，`FilmFrame.tsx` 通过四个 SVG viewBox 只取边框，避开不透明的黑色中心。边框只用于胶片分类的缩略图，普通分类和大图保留原有呈现。

进入胶片分类时，预览图在加载成功后播放约 4.2 秒的拍立得显影动画，从灰白、低对比逐渐显出细节与色彩，相邻照片错开 100ms（最多 600ms）。边框不参与动画，结束后恢复照片原色，不保留滤镜；再次进入会重播，普通数据刷新不重播。系统开启「减少动态效果」时直接显示原图。

胶片分区背景使用用户提供的摄影桌面图片 `public/images/film-desktop.png`，整页覆盖、不重复，叠加轻微暗色以保证文字可读。桌面背景固定，手机随页面滚动；页首仅使用轻薄遮罩，保留桌面图案。

胶片分区的「胶片」按钮使用居中白色文字与加粗状态，不显示图片装饰，同时隐藏原铜色滑块。切到其他分类后，「胶片」按钮恢复原来的普通标签样式；普通分类继续使用原来的选中样式。

选中「胶片」时，整条分类栏使用用户提供的 `public/film-frames/35mm-controls.png`：两侧齿孔、金色磨损边缘和深色底片纹理。`FilmControlFrame` 通过 SVG viewBox 排除透明留白，源图不作修改，装饰层不拦截点击。离开该分类后恢复普通分类栏，照片继续使用原来的横/竖 135 边框。

胶片分区右上角「外观」按钮及「图库 / 发现」切换容器也使用同一胶片边框；保留原来的操作、选中状态与键盘交互，离开胶片分区后恢复普通控件。

胶片分区的「图库」「发现」按钮只显示居中文字，当前选中项通过白色与加粗文字区分，原铜色滑块隐藏，外层胶片边框保留。此前试用的按钮图片素材保留在资源目录中，当前不引用。

选择保存在浏览器的 `pic4pick_theme` 中，刷新、页面导航及同源其他标签页会保持同步。无有效保存值时使用纸白。主题偏好是每位访客的本地选择，不会写入云端或修改站点配置。

`index.html` 在应用加载前设置主题，避免刷新时先显示浅色页面。存储不可用时仍可在当前会话切换。

- `src/themes/themes.css`：配色、界面形态、字体和公共组件样式。
- `src/themes/themeConfig.js`：主题名称、预览色和动效节奏。
- `src/themes/ThemeProvider.jsx`：主题状态、存储同步和切换动效。
- `src/themes/ThemeSwitcher.jsx`：主题入口、预览面板和键盘操作。

动效参考 [GSAP 官方 skills](https://github.com/greensock/gsap-skills)，使用 `useGSAP` 自动清理和 `gsap.matchMedia` 响应「减少动态效果」。按方向键浏览选项，Enter/Space 应用，Escape 关闭。

本地 Vite 服务启动后运行：

```powershell
npm run test:themes
npm run lint
npm run build
```

主题回归测试使用街道栅格地图，使检查不依赖高德 JS SDK 凭据。已有 UI 回归也支持两种地图容器；如需固定地图测试配置：

```powershell
$env:UI_MAP_PRESET = 'street'
npm run test:ui
```
