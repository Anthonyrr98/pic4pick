# 微信发现页：远山黛地图样式

## 当前状态

2026-10-14 用户选择不购买个性化样式，采用默认底图加远山黛配色的方案，随后要求地图铺满屏幕，并将地点标记换回网页同款彩色小圆点。发现页现为通栏地图、顶部悬浮导航与底部抽屉，取消卡片边框、圆角地图和外边距。气泡、城市卡片以及地点照片抽屉保持灰蓝色。道路、水域等仍显示微信默认底图，不能称为高德 whitesmoke 底图的完整复现。

地点圆点沿用网页按分组顺序循环的四色 `#cfa56a` / `#111218` / `#9b9dad` / `#d48a48`，不表示地点类别。网页与小程序共用 `packages/shared/exploreMarkerStyle.js` 中的配色和尺寸约定。圆点直径 9 px、白边 2 px，带外描边和轻阴影；原生标记使用 132×132 的透明 PNG，显示为 44×44 px 点击区，中心锚点为 (0.5,0.5)，坐标对准圆点中心。矢量源与 PNG 在 `miniapp/src/assets/map-dots/`。

图库页面使用自定义导航，按状态栏与微信胶囊位置计算顶部安全区，图库和详情按钮同样避让胶囊。地图从屏幕左上角开始，默认铺到收起的足迹栏上沿；地图底部版权标记保持可见。底栏默认收起，展开后滚动浏览城市，选中城市或照片标记后收起城市列表并显示地点照片。管理入口保留在展开的城市抽屉底部，品牌长按入口也保留。

此方案无需填写地图 Key 或样式编号，不新增地图服务请求。原生卫星/路况开关、真实地点与照片交互保留。地图范围内的配色在纸白/胶片主题下保持一致，图库与详情仍沿用各自主题。照片不加调色滤镜，仅卡片文字的背景使用深蓝灰渐变。

已备好的 `subkey` / `layer-style` 配置入口保持未配置，仅供未来用户改变方案时使用，不是当前交付的前置条件。未开通付费能力。

网页的远山黛是 `amap://styles/whitesmoke`，它属于高德，不能作为腾讯原生地图的样式地址或编号。网页配置页仍保存原高德 / MapLibre 配置，小程序原生配置独立管理。

## 将来如需修改真实底图

1. 在微信公众平台对应 AppID `wxbee87099f5e5d386` 下，进入「管理 → 付费管理 → 概览 → 地图个性化样式 → 去使用」。该能力需要购买；是否开通由用户决定，具体入口与费用以账号当前页面为准。
2. 在该入口提供的编辑平台创建并发布普通底图样式，对照原网页远山黛的灰蓝风格调整水域、道路、背景、绿地与文字。腾讯和高德使用不同底图数据，需逐缩放级别比较，不能保证完全一致。
3. 获取平台给出的专属 Key（subkey）和该 Key 绑定的已发布样式编号，在被 Git 忽略的 `miniapp/.env.local` 中填写：

   ```dotenv
   PIC4PICK_TENCENT_MAP_SUBKEY=
   PIC4PICK_TENCENT_MAP_STYLE_ID=
   ```

   仅填写用于客户端地图的公开 Key，不填 SecretKey。两项必须同时填写；样式编号必须为正整数，不能填网页预设 ID 或高德样式 URL。构建时校验配置，不会自动猜测编号 1。
4. 在 `miniapp` 执行 `npm run build:weapp`，清除开发者工具编译缓存，重新生成并扫码打开预览。subkey / layer-style 不支持直接动态修改，修改配置必须重新构建。
5. 在管理页「地图样式 → 本设备微信地图」关闭卫星底图，再对比发现页中国全景、北京城市视野及海外地点。检查灰蓝色层次、道路与地名可读性、缩放、标记和照片抽屉。配置已填不等于已授权或已生效；实际能力失败时发现页会提示“地图样式未生效，请联系管理员”。

共享预设的 SVG 缩略图使用 `#e4eaef`、`#f2f5f8`、`#b0c8d8`、`#8fa3b0` 作为灰蓝预览色。这些仅是缩略图参考色，不是高德真实底图的完整样式定义，不能据此宣称原生视觉验收通过。
