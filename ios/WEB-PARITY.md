# 网站访客功能对齐记录 · 1.7.2

以当前仓库中的访客前台为基准，客户端保持手机原生导航与交互。此表区分功能实现、自动检查和真机确认，编译通过不代表所有操作已经实机验收。

## 手机端范围与剩余差异（2026-11-03）

按用户最新要求，手机端不做管理员界面。上传、编辑、审核、批量操作、品牌／器材配置及 JSON 导入导出统一在网页维护，不再作为手机端待移植项。原生管理入口已移除，管理源码排除出安装包编译。

访客端仍有以下差异：

- 网页灯箱的左下角品牌水印尚未加入原生照片查看器。
- App 可读取网页配置的品牌 Logo，但尚未实现 SVG 等格式的显示处理；本地 Logo 上传已不属于手机端范围。
- 发现页使用参考图的整屏地图及白色发现面板布局，底图严格跟随用户后台默认配置。地图使用网站组件，面板与照片浏览使用原生视图。

此前记录的上传地址自动回填、器材自动保存、Logo 上传格式及上传 EXIF 备用字段，不再属于手机端待办。已确认正常的真机功能见文末；其他访客操作的异常情况仍需实际验收。

## 共用源与运行方式

- `ios/Web/GalleryShared.ts` 将共享省市归类、地点聚合、日期、标签及媒体 URL 规则构建到 JavaScriptCore；数据通过参数传入，不拼接到可执行脚本。
- `ios/Web/Map.ts` 使用仓库锁定版本的 MapLibre、高德 SDK 和共享样式、标记、地址解析规则；MapLibre Worker 单独打包后以内存 Blob 加载，兼容 v6 模块依赖。
- 地图消息桥只接受主框架消息；地点 ID 必须存在于当前公开列表，地址响应必须匹配当前查询。地图页面不接收管理员 JWT。SDK、地图瓦片和地址服务仍需要网络及现有公开 Web Key 的授权。
- 公开图库仍通过匿名 RLS 只读已审核且未隐藏的作品，服务角色和 OSS 密钥不进入安装包。
- 手势、键盘、保存、分享和导航使用 iOS 对应交互；浏览器 SEO、网页标签页同步、桌面鼠标悬停不属于手机 App 的交互目标。地图网络依赖及第三方 SDK 故障时的回退提示会保留。
