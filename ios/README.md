# 见远方 for iPhone

SwiftUI 原生 iOS 客户端，最低 iOS 17。源码和构建工程位于本目录，使用 WSL Ubuntu、Swift 和 xtool，手机通过 Windows Apple Mobile Device Service 转接连接。

## 功能（1.7.2）

- 信息面板改为连续长页：地理位置下面可继续向上滚到光圈、快门、相机等，底部分区按钮可定位并随滚动更新。在参数卡片、空白或地图区域下拉，内容回顶后可收起；零尺寸几何桥不再遮挡触摸。图片保持同一 bitmap 连续移动／裁剪，原生进度只驱动轻量变换节点。当前用户已确认上下滚动和收起正常，最后反馈目前没有明显卡顿或跳动；没有实测帧率数据。

- 对照参考视频重做信息面板联动：居中照片和顶部裁剪预览使用同一张 UIKit 图片连续移动，不再交叉淡入两张照片；状态栏保持稳定，信息内容滚到顶部后可向下收起，地图手势独立。松手弹簧在结束前连续收敛到零速度，回位后与原卡片做短暂同位置交接。视频分析、实现与真机清单见 [PHOTO-TRANSITIONS.md](PHOTO-TRANSITIONS.md)。

- 照片共享元素预览：图库／城市作品集的真实缩略图放大进入，单指下滑直接跟随移动、缩小并淡化背景；松手从当前状态带速度返回原缩略图，轻拖回弹。来源离屏／被移除时自然缩小淡出，保留原有双击、双指缩放、翻页和上滑参数。架构、改动文件、集中参数和真机验收清单见 [PHOTO-TRANSITIONS.md](PHOTO-TRANSITIONS.md)。当前交互反馈见最新验证记录；实际帧率和部分边界场景仍待专项测量／验收。

- 紧凑品牌栏：圆形头像与网页原版手写 Logo；右上角主题按钮及手动主题切换功能已移除，普通页面固定纸白，胶片分类仍自动进入暗房。主页面只从底部悬浮导航切换。
- 底部仅保留「图库／发现」，改为居中的悬浮玻璃胶囊：横排图标与文字、滑动选中状态；iOS 26 起使用官方 Liquid Glass，旧系统和减少透明度设置提供兼容外观。不显示原全宽白底栏，也不添加省略号或其他底部入口。照片列表增加底部内容间距，发现页城市入口避开胶囊；搜索键盘显示时隐藏胶囊，全屏照片和系统弹层覆盖它。
- 底部按钮共用一个持续存在的深色选中胶囊，在两个按钮之间以 0.2 秒滑动，文字同步变色；支持 RTL，减少动态效果时直接定位。
- 切换时，发现页在图库上方用 0.2 秒淡入或淡出，减少动态效果时直接切换。图库刷新结束后会在后台准备首次进入发现所需的地图，省电、过热或收到内存警告时按需加载。保留图库滚动位置、发现面板和地图状态，隐藏页面不接收触摸及辅助功能焦点。
- 状态栏、品牌／分类栏和图库共用整页背景；顶部容器透明，仅按钮和分类胶囊保留磨砂效果，避免局部图片裁切形成横向色块。
- 一体式磨砂圆角分类栏，选中项使用深色胶囊；与品牌栏一起固定在图库顶部，滚动照片时仍可切换分类。已移除分类下方的作品数量／更新时间整行及占用空间；搜索通过品牌栏右侧放大镜展开，随览分区的重新随机按钮也放在品牌栏。
- 分类切换对齐网页：同一个选中胶囊以 400 ms 的回弹曲线横向滑动，文字轻微抬升、变色，按下有轻缩反馈。动画仅限分类控件，不对照片排序、分页和布局套用全局动画；减少动态效果时直接切换。
- 分类栏 Liquid Glass：iOS 26 起使用官方 `glassEffect(.regular.interactive(...), in: Capsule())`，五个按钮共用一个原生玻璃表面，选中标记改为半透明主题色高亮，避免不透明底色遮住玻璃效果。保留 52 点高度、44 点点击区域及高刷滑动；系统减少动态效果时禁用交互动画，减少透明度时使用实色底板，旧系统保留原磨砂兼容样式。其他顶部控件未在此次统一改造。
- 开启 iPhone ProMotion 高刷新率声明。分类胶囊使用 Core Animation 图层位移，在支持设备上为 400 ms 动画请求 80～120Hz（优选 120）；普通屏幕、低电量和高温条件下降档，不使用常驻 display link。系统“限制帧速率”、温度与电量策略仍可能限制实际刷新率；请求值不等于实测帧率。
- 全局高刷偏好：iOS 18 及以上在整个窗口场景注册被动 `UIUpdateLink`，滚动、导航、查看器和弹层共用最高 120Hz 偏好；不要求持续更新，注册轻量被动回调但不在回调中修改 UI，进入非活跃状态暂停，场景关闭即释放。iOS 17 保留系统自动 ProMotion 与显式分类／空间动画请求。内嵌地图的绘制节奏仍由 WebKit／地图引擎决定，窗口偏好不代表地图逐帧达到 120fps。
- 空间照片在支持设备上请求最高 120Hz，姿态更新频率跟随同一策略，稳定后停止 GPU 绘制；省电／高温时空间渲染降至最高 30Hz，普通界面最高 60Hz。移除固定 60Hz 姿态轮询计时器，改用 Core Motion 数据回调；GPU 成功帧不再逐帧创建主线程任务。

- 原生图库：最新、随览、附近、远方、胶片；地点、相机和胶卷搜索；下拉刷新。
- 普通图库、收藏与城市相册共用整图圆角卡片：3:4 固定版式，左上角分类胶囊，底部渐变叠加白色标题／地点与独立点赞按钮，移除白色信息底板。普通预览按卡片 cover，胶片照片／胶片分区及详情大图保留完整画面和按胶卷匹配的边框。
- 滚动图片流水线：后台 actor 串行解码、缩图与胶片合成，复用相同图片的在途请求并缓存素材；胶片每次进入分类只显影一次，完成后释放滤镜叠层。
- 看过的图片自动写入 App 磁盘缓存，重启后优先读取本地；上限 512 MiB，超出清理最久未使用的图片，单项 7 天到期后重新获取。同一完整 URL 的下载内容跨预览尺寸复用，地址及变换参数不同则分别缓存；不自动下载整个图库，也不自动保存到系统相册。缓存损坏／存储不可用时回退网络，服务器标记 `no-store` 的响应不写磁盘。
- 照片详情按用户参考图使用整图居中、同张照片模糊延展背景、左上角圆形返回按钮；移除原顶栏计数和常驻标题／操作行。底部为白边磨砂信息面板，收起时显示地点、地理位置／基本参数入口及「…」，上拉或点入口展开，再点当前入口、下拉或从菜单收起。
- 信息上滑后切换为整页卡片布局：照片收成顶部预览、下拉箭头留在预览底缘；地理分区使用带地点标题及圆形照片标记的地图卡片，下面以两列近方形卡片展示经纬度／海拔／距离／评级／拍摄时间，基本参数沿用相同卡片。底部固定分区切换及更多入口，并为滚动内容留足间距；展开时隐藏状态栏，适配前后安全区变化，手指拖动同步驱动过渡。
- 可直接在未放大的照片上单指上滑，参数从手指移动时开始显露并跟随展开；从展开态顶部照片预览或下拉箭头单指下滑，参数跟随收回。方向确定、手势开始时仅轻震一次，松手按距离／速度吸附，取消时恢复。原生手势按纵横方向分流，横滑继续翻页，已放大照片的平移和双指缩放不触发面板；空间模式保留原有拖动景深。
- 照片正常浏览时，在照片及空白背景区域单指下滑即可关闭详情；拖动中照片与面板轻微跟手，短距离慢拖会回弹，足够距离或明确向下快速滑动才退出。参数展开时本次下滑只收起参数，回到正常浏览后再次下滑关闭；已放大照片区域继续平移，控件操作不受背景手势遮挡。
- 照片手势性能：逐帧状态由独立对象通知少量位移／透明度修饰器，详情页主体、分页和完整参数内容不订阅拖动更新。展开面板保持固定宽高，仅作平移，避免地图与卡片连续重排；原生参数预备后跟手显示，地图和 EXIF／地址请求在松手吸附结束后延迟启用，收起后再停用。模糊背景在后台生成小尺寸位图并缓存，不在滑动时做全屏实时模糊。
- 照片保持完整比例、胶片边框、左右翻页、双指及双击缩放；常规浏览区避开返回控件与收起面板，更多菜单保留点赞、收藏、分享原图、保存和空间场景。信息面板重绘不会重置图片缩放，空间场景在展开信息、退出和后台时停止。
- 发现页按新参考图使用铺满屏幕的地图和 6 点地点标记，去掉顶部头像栏、地图工具条与旧的城市作品集大按钮。地图引擎恢复为网站组件，严格跟随后台默认配置（当前构建默认为高德 `js_whitesmoke`），不使用 Apple 地图或本机旧样式覆盖；配置样式加载失败时显示重试入口，不自动替换风格。初始镜头对准中国并为面板留白，更多菜单里的「查看全部拍摄地点」可缩放到全部地点，地图署名保留。
- 底部白色圆角面板支持拖动把手展开／收起，提供「搜索地点」「精华选粹」横向城市封面与完整城市作品集；搜索会展开面板，地点圆点和卡片可聚焦地图并打开原生相册。城市归类继续使用网站共享规则，封面从公开作品中按评分挑选，空相册与已下架作品不进入精选。
- 内容列表滑至顶部后可继续下拉收起。面板可以跟手滑过中间档，松手后减速停靠。拖动时列表尺寸固定，仅移动面板，地图和城市索引不参与逐帧更新。横向卡片可以独立滑动，收起面板时关闭键盘。
- 普通页面纸白、胶片临时暗房、桌面背景与显影动画；品牌 Logo、双列图库和详情卡片与网站功能同步。
- 本机收藏、同步网站点赞、分享原图链接、保存原图到相册。
- 原生空间场景：Metal 景深重投影、Core Motion 倾斜、触摸拖动、回正与重新校准。
- 上传、审核和配置统一在网页维护，手机端只提供访客功能。「收藏／我的」不再作为底部独立入口；本机收藏记录不会删除，详情里的收藏操作保留。

完整功能映射与验证范围见 [WEB-PARITY.md](./WEB-PARITY.md)。发现页及照片详情小地图复用网站配置与地图组件；面板、照片查看和空间场景使用原生实现。参考图用于界面布局，不替换用户配置的地图样式。

公开图库只读取 `approved` 且 `hidden=false` 的作品。照片列表缓存有效期为 5 分钟，在前台每分钟重新读取，过期且读取失败时清空列表。收藏只保存照片 ID；图片磁盘缓存用于加快浏览，不提供完整离线图库。图片内存缓存有大小限制，全屏仅预加载相邻照片；系统可以清理 App 缓存目录。

## 原生空间场景

打开照片后在底部「…」菜单选择「空间场景」。可以轻轻倾斜手机或拖动照片；同一菜单中提供倾斜控制、重新校准和上一张／下一张，避免与拖动景深手势冲突。切换照片后恢复普通照片；关闭空间模式后继续使用原来的翻页与缩放。

- `SpatialDepthClient` 使用现有公开 RLS 读取 `photo_spatial`，通过后台签发 OSS 5 分钟链接；也兼容旧 Supabase Storage。签名到期只重试一次，校验照片 ID、生成版本、路径、PNG 格式和尺寸。
- 景深仅保存在内存中，按照片 ID 和生成版本最多保留三张，不缓存签名链接。停留 800 ms 后只预读当前照片的景深，点击复用预读任务；用户点击后才等待未完成的后台任务。低电量模式和减少动态效果下不自动预读。
- `SpatialMetalView` 在 iPhone 上编译打包的 MSL 源码，使用与网页相同的三次逆向景深重投影和 1.045 边缘余量。照片明确转换为 sRGB RGBA 纹理，输出使用 BGRA，避免解码器原生通道顺序或广色域处理差异。
- 胶片边框使用原素材在外侧静态显示，只有照片区域进入空间重投影，边框不随景深变形，也不向照片中央叠加素材。
- `SpatialMath` 对齐网页的 120 ms 跟随、180 ms 回正、64 ms 长帧保护、0.02 输入死区、0.012 抖动过滤及 0.75～1 自动幅度。横竖屏、拖动结束和手动校准均重置姿态基准。
- 渲染稳定后停止 GPU 绘制。关闭效果、换照片、打开信息面板、进入后台或收到内存警告时，取消加载并停止传感器与显示刷新。减少动态效果开启时保留普通照片。
- 这仍是单张照片的 2.5D 视差；复用云端 SharpDepth + UniDepth 结果，手机不运行推理模型，不补画被遮挡的背景。效果不可用时保留普通照片并显示可重试信息。

空间场景不依赖 WebView；完整网站入口仍可打开网站。

## 配置

从仓库根目录运行：

```powershell
node ios/scripts/prepare.mjs
```

脚本按顺序读取根目录 `.env.local`、`.env.production` 和 `miniapp/.env.local`，后者覆盖前者；也接受 `PIC4PICK_*` 进程环境变量覆盖。只输出以下公开客户端配置：

- `PIC4PICK_SUPABASE_URL` / `VITE_SUPABASE_URL`
- `PIC4PICK_SUPABASE_ANON_KEY` / `VITE_SUPABASE_ANON_KEY`（支持 publishable 或旧 anon key）
- `PIC4PICK_API_BASE_URL` / `VITE_API_BASE_URL`
- `PIC4PICK_MEDIA_BASE_URL`（默认为线上网站）
- `PIC4PICK_WEBSITE_URL`（默认 `https://pic.rlzhao.com`）

生成的 `Sources/Pic4Pick/Resources/ClientConfig.json`、边框副本和地图预设均忽略提交。准备脚本需要 Node.js 24 或支持默认 TypeScript 类型剥离的 Node.js 22.18+。脚本拒绝服务端密钥和非 HTTPS 地址。App 不包含管理员密码、服务角色密钥或 OSS 密钥。公开读取显式设置 `Accept-Profile: public`，保留数据库现有 RLS。当前安装包不编译原生管理会话与上传模块。

## 构建和安装

环境细节先看 `G:\Ai\xcode\README.md`。在仓库根目录的 PowerShell 中：

```powershell
# 准备配置、运行模型检查、编译
powershell -NoProfile -ExecutionPolicy Bypass -File ios/scripts/build.ps1

# 编译、签名并安装到已连接且解锁的手机
powershell -NoProfile -ExecutionPolicy Bypass -File ios/scripts/build.ps1 -Install

# 导出签名 IPA
powershell -NoProfile -ExecutionPolicy Bypass -File ios/scripts/build.ps1 -Ipa

# 性能体验与分发使用 Release 优化编译（也可和 -Install 组合）
powershell -NoProfile -ExecutionPolicy Bypass -File ios/scripts/build.ps1 -Ipa -Release
```

或先运行准备脚本，再在 Ubuntu 中执行：

```bash
cd /mnt/f/Github/pic4pick/ios
bash scripts/build.sh build
bash scripts/build.sh install
bash scripts/build.sh ipa
```

输出在 `ios/xtool/`。源码包 ID 为 `com.rlzhao.pic4pick`；当前个人开发者签名后的设备包 ID 为 `XTL-DMY7H5LD37.com.rlzhao.pic4pick`。这是个人开发签名，受 Apple 的有效期和设备限制，过期后重新安装；尚未提交 App Store。
